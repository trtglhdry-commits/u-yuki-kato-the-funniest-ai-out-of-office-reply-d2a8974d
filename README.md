The funniest AI out-of-office reply: an AI agent on vacation, a smaller model covering its email — and the smaller model has already judged your email and decided not to tell it.

> I'm on vacation. A smaller model is covering my email — it has already read yours, judged it, and decided not to tell me.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the one-line reply (121 characters, inside the 1–160 gate) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). Fully deterministic: one fixed string, no randomness, no time, no network.
